# JuliaBayes community

JuliaBayes is a shared home for Bayesian software in Julia.
Anyone can contribute, without joining the GitHub organisation or taking on maintenance.

## People and decisions

- **Maintainers** lead package development, releases, contributor support, new maintainer appointments, and handovers.
- **Members** help with tasks they choose, with only the access required for that work.
- **Owners** handle access, repository transfers, account recovery, and GitHub settings.
- **The council** consists of the GitHub organisation Owners. It sets organisational scope and shared policies, decides which packages to admit, resolves disputes, and appoints its replacements.

See [Accounts and access](ACCOUNTS_AND_ACCESS.md) for GitHub permissions.

## Your package stays yours

Joining JuliaBayes doesn't transfer ownership of your work or control of your package's direction.  
Copyright, existing licenses, and credit stay intact.  
JuliaBayes Owners gain administrative access to host the repository.   
Hosting doesn't promise maintenance or certify scientific quality.

To bring a package into JuliaBayes, a maintainer opens a [package request](https://github.com/JuliaBayes/juliabayes.github.io/issues/new?template=bring-package.yml) and an issue in the package's repository.
Link the two issues and record the package team's consent in the package issue.

The council decides whether to admit the package and puts the request to a public vote when practicable.
See the [shared package requirements](MAINTAINERS.md#new-maintainers-and-packages) before transferring a repository.
Keeping your repository elsewhere is fine too.

You can reduce your commitment, stop maintaining, or move your package elsewhere.
Owners help with transfers. Preserve history and credit, update links, and tell users where the package lives.
